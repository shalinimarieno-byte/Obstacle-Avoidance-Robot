# 🤖 Obstacle Avoidance Robot

## 📌 Overview

The Obstacle Avoidance Robot is an autonomous mobile robot that detects obstacles in its path using an ultrasonic sensor and changes its direction automatically to avoid collisions. This project demonstrates basic autonomous navigation and sensor-based decision making.

---

## 🚀 Features

- Autonomous obstacle detection
- Automatic collision avoidance
- Real-time distance measurement
- Differential drive robot control
- Simple and efficient navigation logic

---

## 🛠️ Technologies Used

- Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- L298N Motor Driver
- DC Motors

## 🔄 Working Principle

1. The ultrasonic sensor continuously measures the distance in front of the robot.
2. If no obstacle is detected, the robot moves forward.
3. When an obstacle is detected within a predefined distance, the robot stops.
4. The robot changes direction by turning left or right.
5. After finding a clear path, it resumes moving forward.

---

## ▶️ How to Run

1. Connect all hardware components.
2. Upload the Arduino code using Arduino IDE.
3. Power the robot using a battery pack.
4. Place the robot on the floor.
5. The robot will automatically detect and avoid obstacles.
